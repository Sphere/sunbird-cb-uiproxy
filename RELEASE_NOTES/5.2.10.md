## Summary

This release refines the `jumbler` pass-percentage behaviour introduced in v5.2.9: instead of defaulting `passPercentage` to `60` when missing, the field is now omitted from the response entirely unless the source assessment JSON provides a positive value.

## ✨ Features

_None — patch release._

## 🐛 Fixes

- **Assessment player** — `jumbler` now includes `passPercentage` in its response only when the source assessment JSON provides a value greater than `0`; otherwise the field is omitted (`8e7f882`).

## ⚠️ Deploy notes & risk

- **Behavioural change:** content with no `passPercentage`, or a value of `0`, in its source JSON will no longer receive a default of `60` (as in v5.2.9) — the field is now absent from the `jumbler` response entirely. Confirm the player handles a missing `passPercentage` correctly.
- No config, schema, or dependency changes.
