## Summary

This release simplifies the `jumbler` pass-percentage check introduced in v5.2.10: the response now includes `passPercentage` whenever the source assessment JSON provides a truthy value, rather than requiring it be strictly greater than `0`.

## ✨ Features

_None — patch release._

## 🐛 Fixes

- **Assessment player** — `jumbler` now checks for the presence of `passPercentage` (truthy check) instead of `passPercentage > 0` before including it in the response (`1272ae3`).

## 🏗️ Build / CI / Infra

_None._

## 📚 Docs / Chore

_None._

## ⚠️ Deploy notes & risk

- **Behavioural change:** non-numeric truthy values for `passPercentage` (e.g. a numeric string like `"60"`) are now passed through as-is, whereas `> 0` would previously coerce and compare them numerically. A `passPercentage` of `0` is still treated as absent either way.
- No config, schema, or dependency changes.
