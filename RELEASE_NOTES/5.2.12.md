## Summary

This release refines the `jumbler` pass-percentage handling to distinguish three cases: no value provided, a value on graded assessment content, and a value on non-assessment (quiz) content.

## ✨ Features

_None — patch release._

## 🐛 Fixes

- **Assessment player** — `jumbler` now: omits `passPercentage` entirely when the source JSON has no value (`null`/`undefined`); passes it through as-is for graded assessment content (`isAssessment: true` on the source); and reports `passPercentage: 0` for non-assessment (quiz) content that has a value (`e5b8cf4`).

## ⚠️ Deploy notes & risk

- **Behavioural change:** quizzes (non-assessment source content) that provide a `passPercentage` will now always report `0` for that field, regardless of the source value. Confirm this is the intended pass-mark behaviour for quizzes in the player.
