## Summary

This release adds a safe default for the assessment pass percentage returned by `jumbler`, preventing an undefined value from being forwarded to the player when the source assessment JSON doesn't specify one.

_None — patch release._

## 🐛 Fixes

- **Assessment player** — `jumbler` now defaults `passPercentage` to `60` when the source assessment JSON does not provide one, instead of forwarding `undefined` to the client (`6838b45`).
